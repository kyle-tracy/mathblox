## 2. Choice quality
- Last run's main weakness, a single true road dressed up as a choice, is fixed. The T-shapes now give the kid a free pick between two working answers, plus a bait arm that fails visibly and safely. That supports autonomy without creating a quiz.
- **The weakest choices are the Agency 3 levels** (L2, L3, L6, L10, L11, L12, L15, L19, L22). Both roads are the same idea with different numbers, so the kid isn't predicting anything different. That is fine for intros and rests.
- **Template fatigue is the main replay risk.**
  - L2, L3, L6, L11 and L15 are the same 15-wide T (two arms plus an up-bait).
  - L19, L22 and L25 are the same lane room: top corridor, four blocks in a row, an empty lane row.
  - L19 also repeats L18's door (△ = 5) and its blocks (3, 2, 4, 1), so its only change is more space.
